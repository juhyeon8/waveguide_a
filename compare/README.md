# 비교 페이지 — 실제 격자 모형 ↔ 하위헌스-장애물 모형

두 앱을 나란히 띄워 같은 조건에서 무엇이 달라지는지 보는 페이지입니다.

## 반드시 로컬 서버로 여세요 — 더블클릭으로는 열리지 않습니다

```
cd Faraday
npx serve .
```
그다음 브라우저에서 **`http://localhost:3000/compare/`** 를 엽니다.

`file://` 로 열면 동작하지 않습니다. `file://` 문서는 브라우저가 **unique origin** 으로
취급해 iframe 사이 통신(`postMessage` · `contentDocument`)이 전부 막히기 때문입니다.
이 프로젝트의 다른 페이지들과 달리 이 페이지만 서버가 필요합니다.

## iframe 주소에 디렉터리 URL 을 쓰는 이유

이 페이지는 좌우 iframe 을 이렇게 가리킵니다:

```html
<iframe src="../?embed=1">          <!-- 실제 격자 모형 -->
<iframe src="../huygens/?embed=1">  <!-- 하위헌스 대조군 -->
```

**`../index.html?embed=1` 로 쓰면 동작하지 않습니다.** `npx serve` 의 clean-URL 기능이
`/index.html` 을 `/index` 로 301 리다이렉트하면서 **쿼리스트링을 버리기** 때문입니다.
실측:

| 요청 | 응답 |
|---|---|
| `GET /index.html?embed=1` | `301 Moved Permanently` · `Location: /index` ← **쿼리 소실** |
| `GET /?embed=1` | `200 OK` ← 쿼리 보존 |
| `GET /huygens/index.html?embed=1` | `301` · `Location: /huygens/index` ← **쿼리 소실** |
| `GET /huygens/?embed=1` | `200 OK` ← 쿼리 보존 |

`embed=1` 이 풀리면 앱의 설정 패널이 그대로 보이면서 캔버스 폭이 0 이 됩니다.
디렉터리 URL 은 `serve` · python `http.server` · nginx 어디서나 동작합니다.

## 구조

- **파동 그림(좌우 3밴드 캔버스)** = iframe. 각 앱을 그대로 띄웁니다.
  `?embed=1` 이 설정 패널을 숨겨 캔버스만 남깁니다.
- **마스터 컨트롤바** = `bridge.js` 프로토콜(`postMessage`)로 양쪽에 동시 전파합니다.
  기존 `script.js` 가 IIFE 라 내부 상태에 접근할 수 없으므로, 슬라이더 값을 바꾸고
  `input` 이벤트를 쏘는 **DOM 이벤트 방식**으로만 제어합니다.
- **하단 정량 패널** = `compare/script.js` 가 **직접 계산**합니다. iframe 통신에
  의존하지 않으므로, 동기화가 실패해도 정량 결과는 살아남습니다.

- **T(λ) 곡선** = 역시 직접 계산합니다. 무한 곡선은 해석식이라 즉시(5 ms 미만),
  유한 곡선은 무거워서(최악 545 ms) **디바운스 250 ms + 취소 토큰**으로 돌립니다.
  계산 중에는 진행 표시가 뜨고, 계산 중 조건이 또 바뀌면 이전 계산을 버립니다.
- **CSV 내보내기** = T(λ) 곡선과 같은 데이터를 파일로 냅니다.

페이지 아래의 진단줄은 배선 확인용이며 정량 패널이 아닙니다.

## ⚠ compare 의 x 범위는 단독 앱과 다릅니다

`?embed=1` 이 설정 패널을 숨기므로 **캔버스의 종횡비가 달라집니다.** 앱은 화면 x 범위를
`Xw = Yw / aspect` 로 잡기 때문에, 종횡비가 바뀌면 **`Xw` 가 달라져 좌우로 보이는 범위가
단독 앱과 달라집니다.**

**정량값은 영향을 받지 않습니다.** 하단 패널과 T(λ) 곡선은 화면 격자가 아니라 고정
정의(`x = 30 mm`, 41 표본, 도선당 적분 표본 64 고정)로 계산하기 때문입니다. 영향을 받는
것은 **파동 그림에 보이는 x 범위뿐**입니다. 논문 그림에 좌우 그림을 실을 때 단독 앱
캡처와 나란히 놓지 마십시오 — 축척이 다릅니다.

## ⚠ `a/d` 유효 범위 — 논문에 쓰기 전에 확인하세요

원본 격자 모형의 Floquet 해는 `floquetZ` 의 **임피던스 시트 근사**를 쓰는데, 이 근사의
오차가 `a/d` 에 계통적으로 커집니다. `T + R` 이 1 에서 벗어나는 정도로 잴 수 있습니다.

| `a/d` | λ ≫ d | λ < d | 판단 |
|---|---|---|---|
| **≤ 0.05** | 0.3 % 이내 | 최대 5 % | **안전 — 그대로 사용** |
| 0.10 | 9 % 이내 | 최대 84 % | 오차를 명시하면 사용 가능 |
| **0.30** | 15 % 이내 | **최대 21,594 %** | **`λ < d` 는 논문 사용 불가** |

기본 조건(`d = 10 mm · a = 0.5 mm`)은 `a/d = 0.05` 로 안전한 줄입니다. 다만 **반지름
슬라이더를 끝까지 밀면 `a/d = 0.30`**(`A_RATIO_MAX` 상한)에 닿습니다. CSV 주석에 현재
`a/d` 와 이 표가 함께 나갑니다. 자세한 것은 `../HANDOFF.md` §7-1.

관련 현상 하나 — **원본 앱은 `λ < d` 에서 `T > 100 %` 를 표시합니다**(최대 133.3 %).
전력 투과율이 1 을 넘을 수 없으므로 수치 인공물입니다. T(λ) 곡선은 이 점들을 **끊어서**
그리고, CSV 에는 원값을 남깁니다.

## 논문 그림 캡처 — 토글 두 개의 방향이 반대입니다

| 대상 | 토글 | 캡처 시 | 이유 |
|---|---|---|---|
| **밴드 그림** (좌우 파동 캔버스) | `DRAW_BAND_TITLES` | **`false`** (끈다) | 그림 위에 글자가 얹히지 않는 편이 깔끔합니다. 끄면 캔버스에 글자가 하나도 남지 않습니다 |
| **T(λ) 곡선** | `LEGEND_IN_CANVAS` | **`true`** (켠다) | 범례와 두 정의가 없으면 그림만으로 읽을 수 없습니다. 켜면 x 축 아래 별도 띠에 범례·정의·경고가 들어가 캔버스 하나로 완결됩니다 |

**헷갈리기 쉬우니 함께 적습니다 — 하나는 끄고 하나는 켭니다.**
`LEGEND_IN_CANVAS` 는 페이지의 체크박스로 바로 켜고 끌 수 있습니다.

캡처할 때 기록할 값은 `../HANDOFF.md` §6 의 체크리스트를 따르십시오 (특히 `a/d`,
`d/λ`, 그리고 **T(λ) 캔버스의 CSS 폭** — 창 폭에 따라 달라집니다).

## CSV 내보내기

`T(λ) 곡선` 블록의 **CSV 내보내기** 버튼을 누르면 받습니다.

```
lam_cm, d_mm, a_mm, N, T_inf_grid, T_inf_huygens, T_fin_grid, T_fin_huygens,
T_plus_R, rayleigh_flag
```

- **λ 1~30 cm 를 0.1 cm 간격 291행.** `T_fin_*` 는 0.5 cm 격자(59점)에서만 계산하므로
  **나머지 232행은 빈 칸**입니다. 격자 차이일 뿐이며 화면 탭과는 무관합니다 —
  **유한 값은 어느 탭을 보고 있든 항상 채웁니다.**
- **값은 반올림하지 않습니다.** 표시용 반올림이 참고 수치표에서 이미 한 번 문제를
  만들었기 때문입니다.
- 파일 첫머리 주석에 **두 정의**, 내보낸 시각, `a/d` 와 유효 범위 경고,
  `T_inf_grid > 1` 이 물리값이 아니라는 것, `T_fin_*` 는 1 을 넘을 수 있다는 것,
  `N` 이 유한 열에만 적용된다는 것이 모두 들어갑니다.
- 엑셀에서 한글 주석이 깨지지 않도록 **UTF-8 BOM** 을 붙입니다.

> **`T_inf_*` 와 `T_fin_*` 를 같은 열에서 비교하지 마십시오.** 정의가 다릅니다 —
> 무한은 **전파 회절차수 전력합**, 유한은 **측정창 평균 `|E|²`** 입니다.
> 그래서 유한 값은 간섭으로 100 %를 넘을 수 있고 그것이 물리입니다.

## 비교는 E∥ 조건에서만 정의됩니다

하위헌스-장애물 모형은 스칼라 이론이라 편광 개념이 없습니다. E⊥ 에서는 두 모형의
대응이 성립하지 않으므로 마스터 컨트롤바에 편광 선택을 두지 않습니다.
