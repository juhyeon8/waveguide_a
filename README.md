# 패러데이 차폐 — 도선 격자 모형과 하위헌스-프레넬 장애물 모형

도선 격자(금속망)에 의한 전자기파 차폐를 **입사파 + 각 도선 유도전류의 산란파 중첩**으로
계산해 보여 주는 교육·논문용 시각화입니다. 여기에 도선을 "파동이 나오지 않는 단순 장애물"로
취급하는 **하위헌스-프레넬 대조군**을 나란히 두었습니다. 대조군의 투과율은 `(1−2a/d)²` 로
**파장에 완전히 무관**해서, 파장이 아무리 길어져도 차폐가 생기지 않습니다 — **"패러데이 차폐는
기하학적 가림이 아니라 유도전류의 재방사"** 라는 논지의 정량적 반례입니다.

## 세 앱

| 주소 | 내용 |
|---|---|
| `/` | **원본 격자 모형.** 무한 배열(Floquet 정확해) · 유한 배열(MoM) 두 탭 |
| `/huygens/` | **하위헌스-장애물 대조군.** 같은 화면 구성, 물리만 다름 |
| `/compare/` | **좌우 비교 페이지.** 마스터 컨트롤바 · 정량 패널 · T(λ) 곡선 · CSV 내보내기 |

원본 앱 패널의 **"도선 격자 모형과 하위헌스-프레넬 모형의 비교"** 버튼으로도 `/compare/` 에
갈 수 있습니다.

## 실행

```
cd Faraday
npx serve .
```

`http://localhost:3000` 으로 접속합니다. `start.bat` 을 더블클릭하면 서버를 띄우면서 비교
페이지까지 열어 줍니다(윈도우 · 로컬 전용이라 저장소에는 넣지 않았습니다).

**`file://` 더블클릭으로는 `/compare/` 가 열리지 않습니다** — `file://` 문서는 unique origin
이라 iframe 통신이 막힙니다. 원본 앱과 대조군은 더블클릭으로도 열리며, 그때는 비교 버튼
자리에 안내 문구가 나옵니다.
